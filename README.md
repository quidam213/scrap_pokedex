# scrap_pokedex
This is a peek of what scraping can do.

# Technologies
It's written in Python, it uses theses dependences :
- Pandas to stock data and simplify the handling
- Selenium to scrap while using a webdriver (Firefox / Chrome) to interact with the page dynamically (js)
- Requests to scrap a static page
- BeautifulSoup to parse easily the code source of the pages

# How to use
Juste execute the file <scrap.py> (with the methods of your choice, change the commented line : Selenium / Requests) and let the script run.
